### Climbing Competition Management System

An integrated solution for timing, judging, scoring, and publishing results for sport climbing competitions, supporting **Festival** and **Boulder** formats.

The system is composed of four applications:

- **Judge** — Web application used by the competition team for timing and judging operations.  
  **Technologies:** Angular 17, TypeScript, Angular Material, Bootstrap, RxJS.

- **Judge API** — Backend responsible for centralizing competition data and supporting the scoring and results workflow.  
  **Technologies:** Java 17, Spring Boot 3, Spring Data JPA, PostgreSQL, Maven.

- **Ranking Público** — Web application for displaying competition results to athletes, organizers, and spectators. Includes QR Code-related functionality.  
  **Technologies:** Angular 19, TypeScript.

- **Ranking Nuvem** — Cloud-oriented application for publishing and making competition results available online.

### Ranking Público — QR Code

The public results application is part of the climbing competition system described above and presents the results generated by the judging and scoring workflow.

*These project descriptions are provided for portfolio purposes only. All four climbing competition repositories, as well as the Avaliação Física repository, remain private. No source code is made publicly available.*
