### Climbing Competition Management System

An integrated solution for timing, judging, scoring, and publishing results for sport climbing competitions, supporting **Festival** and **Boulder** formats.

The system is composed of four applications:

- **Judge** — Web application used by the competition team for timing and judging operations.  
  **Technologies:** Angular 17, TypeScript, Angular Material, Bootstrap, RxJS.

- **Judge API** — Backend responsible for centralizing competition data and processing the competition's scoring workflow.  
  **Technologies:** Java 17, Spring Boot 3.2.5, Spring Data JPA, PostgreSQL, Maven.

- **Ranking Nuvem** — Backend that receives partial or overall stage results as JSON from Judge API, persists the information in PostgreSQL, and exposes REST endpoints for the public ranking application.  
  **Technologies:** Java 17, Spring Boot 3.2.5, Spring Web, Spring Data JPA, PostgreSQL, Maven.

- **Ranking Público** — Angular web application that consumes Ranking Nuvem endpoints, allowing athletes, organizers, and spectators to follow the stage as it evolves, check athlete standings, and view detailed athlete activity. Includes QR Code functionality.  
  **Technologies:** Angular 19, TypeScript.

### Competition Results Workflow

1. Competition timing and judging are performed in Judge.
2. Judge API processes the competition data and sends partial or overall stage results as JSON.
3. Ranking Nuvem stores the received results and makes them available through REST endpoints.
4. Ranking Público consumes those endpoints to display live stage progress, athlete positions, and detailed information about each athlete's performance.
